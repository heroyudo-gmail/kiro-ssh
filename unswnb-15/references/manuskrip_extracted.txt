Abstrak
Sistem deteksi intrusi berbasis machine learning sering menunjukkan performa sangat tinggi pada evaluasi within-dataset, namun reliabilitasnya menurun ketika diterapkan pada dataset dengan distribusi trafik dan karakteristik ekstraksi fitur yang berbeda. Penelitian ini menyajikan kerangka Explainable Artificial Intelligence (XAI) untuk Network Intrusion Detection System (NIDS) dengan pipeline bebas kebocoran dan evaluasi generalisasi lintas dataset. Eksperimen menggunakan CIC-IDS-2017 sebagai dataset referensi dan sepuluh partisi CSE-CIC-IDS2018 sebagai dataset target. Pipeline meliputi normalisasi label dan nama kolom, harmonisasi skema fitur berbasis referensi, stratified subsampling, pembagian latih-uji, seleksi fitur hanya pada data latih, standardisasi berbasis data latih, serta SMOTE hanya pada data latih. Model referensi yang tersimpan pada artefak eksperimen adalah Random Forest. Pada evaluasi within-dataset, model mencapai F1-score 0,9963, MCC 98,54%, dan AUC-ROC 0,9997. Namun, pada evaluasi lintas dataset, rata-rata F1 tertimbang masih tampak tinggi (0,7864) sementara MCC seluruh target menjadi 0,00%, dengan recall kelas serangan bernilai 0 pada seluruh partisi CSE-CIC-IDS2018. Hasil ini menunjukkan bahwa F1 tertimbang dan akurasi dapat menyesatkan pada dataset tidak seimbang ketika model cenderung memprediksi kelas mayoritas. Analisis SHAP mengidentifikasi Bwd Packet Length Min, Flow Duration, Fwd URG Flags, Bwd Packet Length Max, dan Average Packet Size sebagai fitur global terpenting, tetapi stabilitas fitur tidak cukup untuk menjamin generalisasi. Temuan ini menegaskan perlunya pelaporan MCC, recall per kelas, dan validasi lintas dataset dalam riset IDS.
Kata kunci: explainable AI, intrusion detection, generalisasi lintas-dataset, SHAP, MCC, data leakage

EXPLAINABLE ARTIFICIAL INTELLIGENCE FOR NETWORK INTRUSION DETECTION SYSTEM: INTERPRETABILITY ANALYSIS AND CROSS-DATASET GENERALIZATION ON LEAK-FREE PIPELINES
Abstract
Machine learning-based intrusion detection systems often achieve high within-dataset performance, yet their reliability degrades when deployed on datasets with different traffic distributions and feature extraction characteristics. This study presents an Explainable Artificial Intelligence (XAI) framework for Network Intrusion Detection Systems (NIDS) using a leakage-free pipeline and cross-dataset generalization analysis. The experiments use CIC-IDS-2017 as the reference dataset and ten CSE-CIC-IDS2018 daily partitions as target datasets. The pipeline includes label and column normalization, reference-based feature schema harmonization, stratified subsampling, train-test splitting, train-only feature selection, train-only standardization, and train-only SMOTE. The reference model stored in the experimental artifacts is Random Forest. In the within-dataset evaluation, the model achieves F1-score of 0.9963, MCC of 98.54%, and AUC-ROC of 0.9997. In cross-dataset evaluation, however, the average weighted F1 remains apparently high (0.7864), whereas MCC collapses to 0.00% for all targets and attack-class recall is 0 across all CSE-CIC-IDS2018 partitions. These results demonstrate that weighted F1 and accuracy can be misleading under class imbalance when a model predicts the majority class. SHAP analysis identifies Bwd Packet Length Min, Flow Duration, Fwd URG Flags, Bwd Packet Length Max, and Average Packet Size as the most important global features, but feature stability alone is insufficient to guarantee transferability. The findings emphasize the need to report MCC, per-class recall, and cross-dataset validation in IDS research.
Keywords: explainable AI, intrusion detection, cross-dataset generalization, SHAP, MCC, data leakage
1. PENDAHULUAN
Transformasi digital memperluas permukaan serangan jaringan dan meningkatkan kebutuhan terhadap Intrusion Detection System (IDS) yang adaptif. Pendekatan machine learning (ML) banyak digunakan karena mampu mempelajari pola trafik dari dataset benchmark seperti CIC-IDS-2017 dan CSE-CIC-IDS2018. Akan tetapi, performa tinggi pada evaluasi within-dataset tidak selalu merepresentasikan kemampuan operasional di lingkungan jaringan yang berbeda. Studi generalisasi lintas-dataset sebelumnya menunjukkan bahwa model IDS sering mengalami penurunan signifikan ketika distribusi data latih dan data uji tidak identik (Dâ€™hooge dkk., 2020; Cantone dkk., 2024).
Keterbatasan lain adalah karakter black-box pada model berperforma tinggi. Bagi analis Security Operation Center (SOC), prediksi tanpa penjelasan sulit digunakan untuk triase alarm, validasi false positive, dan penelusuran indikator serangan. Explainable Artificial Intelligence (XAI), terutama SHAP dan LIME, menyediakan mekanisme untuk menghubungkan keputusan model dengan kontribusi fitur, baik pada tingkat global maupun lokal (Lundberg dan Lee, 2017; Ribeiro dkk., 2016; Molnar, 2022).
Dua persoalan metodologis masih perlu diperkuat dalam penelitian IDS berbasis ML. Pertama, data leakage dapat muncul ketika seleksi fitur, standardisasi, atau oversampling dilakukan sebelum pembagian data latih dan data uji. Leakage menghasilkan estimasi performa yang terlalu optimistis karena statistik data uji telah memengaruhi model. Kedua, kesesuaian skema fitur tidak menjamin kesesuaian distribusi. Walaupun nama fitur telah dinormalisasi dan jumlah fitur cocok, nilai statistik fitur dapat tetap berbeda pada lintas dataset karena perbedaan hari perekaman, komposisi serangan, dan konfigurasi CICFlowMeter.
Kontribusi penelitian adalah: (1) merancang pipeline bebas kebocoran untuk eksperimen IDS biner; (2) mengevaluasi generalisasi model referensi CIC-IDS-2017 pada sepuluh partisi CSE-CIC-IDS2018; (3) menunjukkan bahwa F1 tertimbang dan akurasi dapat menyesatkan ketika model gagal mendeteksi kelas serangan; dan (4) menganalisis stabilitas fitur menggunakan SHAP untuk memahami konsistensi mekanisme keputusan model.

2.2 Pipeline Bebas-Kebocoran
Pipeline dirancang agar seluruh operasi fitting hanya menggunakan data latih. Urutan pemrosesan adalah sebagai berikut.
â€¢ Normalisasi kolom dan label: nama kolom dibersihkan dari variasi whitespace/BOM, alias umum antar versi CICFlowMeter dipetakan ke nama referensi, dan kolom label dipulihkan secara header-based maupun value-based untuk mengatasi CSV dengan header tidak konsisten.
â€¢ Pembersihan data: kolom metadata seperti IP, port, protocol, timestamp, dan flow identifier dikeluarkan dari ruang fitur. Duplikasi dihapus, nilai tak hingga dikonversi menjadi NaN, kolom dengan missing value dominan dibuang, dan sisa missing value pada fitur numerik diisi dengan median.
â€¢ Harmonisasi skema fitur: CIC17 dijadikan referensi fitur numerik. Dataset target disesuaikan ke 75 fitur referensi melalui normalisasi nama dan penyusunan ulang kolom. Fitur non-referensi dibuang dan fitur referensi yang tidak ditemukan diisi nilai 0 agar dimensi input konsisten.
â€¢ Subsampling dan pembagian data: sampling dilakukan secara stratified dengan hard floor 50 sampel dan soft floor 200 sampel untuk mengurangi hilangnya kelas minoritas. Data kemudian dibagi 80% untuk pelatihan dan 20% untuk uji secara stratifikasi.
â€¢ Seleksi fitur, standardisasi, dan SMOTE: Random Forest 50 estimator digunakan untuk memilih 20 fitur teratas hanya dari data latih. StandardScaler disesuaikan pada data latih dan diterapkan ke data uji. SMOTE hanya diterapkan pada data latih, sehingga data uji tetap merepresentasikan distribusi asli.
Keputusan penting dalam pipeline ini adalah tidak menggunakan data uji untuk digunakan ulang dalam proses fitting berikutnya. Pada evaluasi lintasdataset, model referensi, scaler, dan daftar 20 fitur hasil seleksi dari CIC17 digunakan langsung pada target CSE-CIC-IDS2018. Dengan demikian, evaluasi lintas dataset mengukur kemampuan transfer model, bukan kemampuan model beradaptasi ulang terhadap target.
2.3 Model Klasifikasi
Delapan model dievaluasi pada tahap pelatihan: Decision Tree, Random Forest, Gradient Boosting, XGBoost, LightGBM, Logistic Regression, K-Nearest Neighbors, dan Gaussian Naive Bayes. Berdasarkan artefak eksperimen lintas dataset yang tersedia, model referensi tersimpan adalah RandomForestClassifier yang dilatih pada CIC17. Model referensi ini digunakan untuk seluruh evaluasi dari CIC17 ke CSE-CIC-IDS2018 dan analisis SHAP lintas target.
2.4 Metrik Evaluasi
Evaluasi within-dataset dan lintas dataset menggunakan evaluasi performasi model seperti : accuracy, precision, recall, weighted F1-score, AUC-ROC, dan Matthews Correlation Coefficient (MCC). MCC diprioritaskan pada evaluasi lintas-dataset karena memperhitungkan TP, TN, FP, dan FN secara simultan serta tetap informatif ketika data tidak seimbang. Weighted F1 tetap dilaporkan karena umum digunakan dalam literatur IDS, tetapi hasil penelitian ini menunjukkan bahwa weighted F1 harus dibaca bersama MCC dan recall per-kelas.
2.5 Explainability dengan SHAP dan LIME
SHAP digunakan untuk mengukur kepentingan fitur secara global pada setiap target dataset. Untuk setiap pasangan data latih ke data uji, fitur diberi peringkat berdasarkan mean absolute SHAP value; stabilitas fitur dihitung dari rata-rata peringkat dan standar deviasi peringkat pada seluruh target. Korelasi Spearman digunakan untuk mengevaluasi kesamaan peringkat fitur antar-target. LIME tersedia dalam pipeline eksperimen sebagai mekanisme penjelasan lokal, tetapi artefak revisi yang tersedia terutama memuat keluaran SHAP lintas dataset. Oleh karena itu, hasil utama XAI pada naskah ini difokuskan pada stabilitas fitur SHAP.

Pada evaluasi within-dataset CIC17, RandomForestClassifier mencapai F1-score 0,9963, MCC 98,54%, accuracy 0,9963, dan AUC-ROC 0,9997. Hasil ini menunjukkan bahwa pemisahan kelas Normal/Benign dan Attack pada ruang fitur CIC17 sangat kuat ketika pipeline bebas kebocoran diterapkan. Akan tetapi, skor near-perfect ini tidak boleh langsung ditafsirkan sebagai bukti kesiapan operasional lintas lingkungan. Generalisasi harus diuji pada dataset target yang tidak digunakan selama proses pelatihan maupun seleksi fitur.

3.3 Diskrepansi Weighted F1 dan MCC
Subseksi ini membahas tentang adanya diskrepansi antara Weighted F1 dan MCC. Pada seluruh partisi CSE-CIC-IDS2018, precision, recall, dan F1 untuk kelas Attack bernilai 0,00. Sebaliknya, kelas Normal memperoleh recall 1,00. Dengan kata lain, model secara efektif memprediksi hampir seluruh sampel sebagai Normal/Benign. Pada target dengan proporsi Attack sangat kecil, seperti pada data set CIC18_FRIDAY-2 dan CIC18_THURSDAY-2 yang masing-masing hanya memiliki 40 sampel Attack pada data uji, weighted F1 mendekati 0,996 meskipun tidak ada satu pun serangan yang terdeteksi.
Temuan ini memiliki implikasi metodologis yang kuat. Weighted F1 dan accuracy tidak cukup untuk mengevaluasi IDS pada skenario lintas dataset yang tidak seimbang. Model yang tidak mendeteksi serangan tetap dapat memperoleh skor tinggi karena kelas mayoritas mendominasi rata-rata tertimbang. Sebaliknya, MCC bernilai 0 ketika prediksi tidak berkorelasi dengan label aktual, sehingga lebih sesuai sebagai metrik primer untuk generalisasi IDS. Oleh sebab itu, setiap studi IDS lintas dataset sebaiknya melaporkan MCC, confusion matrix, dan recall kelas Attack secara eksplisit.

3.6 Implikasi terhadap Riset dan Operasional IDS
Hasil eksperimen memberikan tiga implikasi. Pertama, evaluasi within-dataset tidak cukup untuk menilai kelayakan model IDS. Skor within-dataset mendekati sempurna dapat muncul sekalipun model tidak mampu mendeteksi serangan pada dataset lain. Kedua, MCC dan recall kelas Attack harus menjadi metrik wajib, terutama pada evaluasi lintas dataset dan dataset tidak seimbang. Ketiga, XAI perlu dibaca bersama metrik performa. SHAP dapat menunjukkan fitur yang secara konsisten dipakai model, tetapi keputusan operasional tetap harus mempertimbangkan apakah prediksi berhasil mendeteksi kelas serangan.
Dari sudut pandang implementasi SOC, model seperti ini belum layak digunakan secara langsung pada lingkungan baru tanpa validasi domain. Jika model memprediksi hampir seluruh trafik sebagai Normal, maka risiko false negative menjadi sangat tinggi. Untuk penggunaan praktis, diperlukan validasi pada trafik lokal, kalibrasi ulang, pembelajaran multi-dataset, dan pemantauan drift distribusi fitur.
3.7 Keterbatasan
Penelitian ini memiliki beberapa keterbatasan. Pertama, grid eksperimen yang tersedia hanya menggunakan CIC17 sebagai model referensi; pelatihan model referensi pada setiap partisi CIC18 belum dilaporkan. Kedua, eksperimen menggunakan skema biner, sehingga belum mengukur kemampuan model membedakan jenis serangan spesifik. Ketiga, interpretasi XAI difokuskan pada SHAP. Keempat, strategi pengisian fitur hilang dengan nol dan harmonisasi nama fitur belum cukup mengatasi pergeseran distribusi. Penelitian lanjutan perlu mengevaluasi harmonisasi berbasis domain, adaptation learning, dan pelatihan multi-source.
4. KESIMPULAN
Penelitian ini menyajikan evaluasi XAI untuk NIDS dengan pipeline bebas kebocoran dan validasi lintas dataset. Model referensi Random Forest yang dilatih pada CIC17 mencapai F1-score 0,9963, MCC 98,54%, dan AUC-ROC 0,9997 pada evaluasi within-dataset. Namun, ketika diuji pada sepuluh partisi CSE-CIC-IDS2018, rata-rata weighted F1 tetap tampak tinggi sebesar 0,7864, sedangkan MCC seluruh target turun menjadi 0,00%. Diskrepansi  nilai weighted F1  dan MCC menunjukkan bahwa recall kelas Attack bernilai 0 pada seluruh target, sehingga model pada dasarnya gagal mendeteksi serangan 
Temuan tersebut menegaskan bahwa weighted F1 dan accuracy tidak dapat dijadikan metrik tunggal dalam evaluasi IDS lintas dataset. MCC, recall kelas Attack, dan confusion matrix wajib dilaporkan untuk menghindari kesimpulan optimistis yang menyesatkan. Analisis SHAP menunjukkan bahwa fitur seperti Bwd Packet Length Min, Flow Duration, Fwd URG Flags, Bwd Packet Length Max, dan Average Packet Size stabil sebagai fitur penting, tetapi stabilitas fitur tidak otomatis menghasilkan transferabilitas model. Penelitian lanjutan perlu memperluas evaluasi ke grid dimensi NÃ—N penuh, klasifikasi multi-kelas, harmonisasi fitur berbasis domain, dan teknik domain adaptation agar model IDS lebih robust terhadap pergeseran distribusi jaringan.
